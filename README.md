# SENAC - TÉCNICO EM DESENVOLVIMENTO DE SISTEMAS
## UC Desenvolvimento Web


Nesta unidade vamos desenvolver *Frontend* e o *Backend* de uma aplicação Web, para simular o ambiente real de trabalho.

## Backend
O back end será desenvolvido em .net8 modelo de Web API Rest.

## Frontend
Para o frontend vamos usar técnologias como Html, Css, Js, 3s e Typescrypt com Angular.
